What's the project about?

What is EduBook?

EduBook is a web platform that brings all university events together in one place.

It connects universities with students and people who are looking for talks, workshops, and academic events in Spain.

Why was the project done?

The Main Problem

Right now, every university posts their events on different websites and social media.

Because the information is everywhere, it is very hard for students to find good events and keep track of them.

Our Motivations

We believe that finding a good academic path should be easy.

We want to make education accessible for everyone, helping students discover their true vocation without stress.

Goals & Objectives

Our Goals

  • Centralize: Put all university events on one single website.

  • Connect: Bring universities and students closer together.

Our Objectives

  • Simplify: Make the registration process fast and easy for students.

  • Empower: Give universities a dashboard to create and manage their events.

The Company

Mission

To group all academic events in one place, connecting universities with students easily.

We want to remove all the barriers that stop students from finding educational opportunities.

Vision

To become the number one platform for educational events in Spain.

We see a future where every student has immediate access to find their true academic path.

Values

Accessibility, Innovation, and building a great Community.

We use modern technology to make education open to all and create a strong student network.

Technical Explanation (I)

In order to develop the front-end, we worked on the structure of our page carefully.

Firstly, Figma, which is a designing tool similar to Wix, was used to design the first prototype of the web.

Technical Explanation (II)

Front-End

  • HTML5 for the structure
  • Vanilla CSS for styles
  • JavaScript for animations

Back-End & Data

  • PHP (MVC Architecture)
  • Role system (Explorador/Manager)
  • Local JSON files for data

Afterwards, coding was written by means of using Visual Studio Code.

Advanced Features (III)

Extra Technologies

Instead of a normal database, we used a modern Serverless system.

n8n Webhooks Supabase AI Chatbot
  • We used n8n and Supabase to do the Login and Register securely.
  • We added an AI Chatbot on our website that can answer any questions.

Conclusion to the Project

Overall, we conclude that EduBook is a great solution for the university events problem.

  • We successfully built a working website with advanced tools like n8n and AI.

  • This website will make life much easier for students looking for orientation.

Teamwork & Difficulties

  • How we worked as a team:

    We communicated every day. One focused more on the design (Front-end) and the other on the PHP logic (Back-end).



  • Challenges & Difficulties:

    Connecting PHP sessions with n8n workflows and JSON files was very difficult, but we learned a lot and made it work.

Suggestions for the future

For future teamwork, we suggest:

  • Planning our time better using agile methods like Scrum.

  • Testing the code together more often to avoid bugs.

  • Learning more about new tools like n8n before starting to code.
